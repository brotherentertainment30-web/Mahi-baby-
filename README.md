## 📱 How to Install the Application

### Option 1: One-Click Direct PWA Install (Android / Windows / Mac / Chrome)
1. Open the application in your browser (Google Chrome, Microsoft Edge, or Android Chrome).
2. Click the **"Install App"** button in the top header, or tap the browser menu (**⋮**) and choose **"Install App"** / **"Add to Home screen"**.
3. Mahi will be installed as a standalone, full-screen native-like application on your mobile phone or desktop without address bars.

### Option 2: Install on iPhone / iPad (Safari)
1. Open the application in **Safari**.
2. Tap the **Share** button at the bottom of the screen.
3. Scroll down and select **"Add to Home Screen"**.
4. Tap **"Add"** in the top right corner.

## 💻 How to Install & Run from GitHub

If you want to clone and run this repository locally on your computer:

```bash
# 1. Clone the repository
git clone https://github.com/brotherentertainment30-web/Mahi.git

# 2. Enter project folder
cd Mahi

# 3. Install dependencies
npm install

# 4. Create your .env file
echo "GEMINI_API_KEY=your_gemini_api_key_here" > .env

# 5. Start development server
npm run dev
```

Visit `http://localhost:3000` in your browser.
